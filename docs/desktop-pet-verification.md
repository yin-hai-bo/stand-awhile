# 桌面 Pet 验证说明

## 当前行为

同一 Windows 登录会话只运行一个实例，使用 `Local\Yinhaibo.StandAwhile`
命名互斥量。不带 `--autostart` 的重复启动最多等待 5 秒寻找已有主窗口，找到后恢复显示并尝试置前，
不修改计时或 Pet 状态；未找到则提示错误并退出，不创建第二个实例。
主实例正常退出或异常终止后，可再次启动。带 `--autostart` 的重复启动静默退出，
不改变已有窗口、计时或 Pet 状态，无论当前开机自启动配置是否开启。

每次普通启动时只显示主窗口，Pet 保持隐藏，计时器处于 `NotStarted`，不会自动开始计时。
带 `--autostart` 且 `launch_at_startup=true` 时，主窗口从创建起隐藏，
Pet 保持隐藏，仅显示托盘图标，并立即开始完整倒计时；该配置为 `false` 时仍普通启动。
主窗口三个按钮下方显示“倒计时结束后，小伙伴会提醒你起来活动活动。”，支持中英文和主题切换。
提醒时 Pet 播放原地 `walk`；气泡显示期间切换为 `idle`，气泡隐藏后回到
`walk`。动画不会自动改变桌宠位置，入场、退场和拖动会改变窗口位置。

点击 Pet 会滑出隐藏，并从配置的完整时长开始新一轮计时。开始按钮会
隐藏 Pet 并开始或继续计时；暂停会停止计时并隐藏 Pet；重置会恢复配置
时长、停止计时并保持 Pet 隐藏。

主窗口底部左侧显示“开始倒计时后自动隐藏主窗口”复选框，默认勾选，
选择立即保存到配置，重启后保留。勾选时，从主窗口、Pet 或菜单开始计时、
暂停后继续、重置后开始以及点击到期提醒，都会隐藏主窗口。取消勾选时，
上述手动操作均不自动隐藏。后台启动始终隐藏主窗口，不受该选项影响。
切换勾选状态不立即隐藏窗口，只影响之后的开始操作。
此行为与关闭窗口时是否缩到托盘的设置无关，隐藏后可从托盘重新打开主窗口。
设置面板同时提供“开始后自动隐藏主窗口”的“是／否”单选项，立即保存，
与主窗口复选框使用同一配置并同步选择。
设置面板提供“开机自启动：是／否”，默认“否”，选择立即保存到
`launch_at_startup` 配置字段，并立即注册或删除当前用户的 Windows 登录启动项，
详细行为和失败恢复见下文“Windows 登录自启动”。
进入设置时焦点位于倒计时分钟数输入框；Tab 导航包含“重置为默认值”和右下角“返回”按钮，
并循环回到输入框，Shift+Tab 可反向导航。
主窗口的 Tab 顺序为开始、暂停、重置、自动隐藏复选框、关于、设置，再循环；
禁用的按钮自动跳过，Shift+Tab 反向导航。计时按钮显示焦点框，空格或 Enter 触发。
页脚按钮可用空格触发。输入框内 Enter/Escape 不会误打开设置或关于。
最小化主窗口后，从托盘或 Pet 菜单打开设置，以及从 Pet 菜单显示主窗口，均会恢复窗口。

计时归零后，主窗口停止计时器，Pet 从所在显示器较近的顶部或底部边缘
以 `jump` 入场，目标位置限制在工作区内。入场和 Jump 都完成后切换到
`walk`，再延迟 500 ms 显示气泡。气泡显示 5 秒、隐藏 10 秒，循环播放
固定提醒和点击说明；文字跟随应用语言，支持中文和英文。主窗口计时文本
停留在配置的完整倒计时时长，重置按钮禁用，开始按钮可开始完整的新一轮倒计时。

倒计时按每条 `WM_TIMER` 消息减一秒，允许偶尔几秒到十几秒的延迟，
不要求精确的实际经过时间；见 [ADR 0003](adr/0003-countdown-timing-tolerance.md)。

关闭主窗口默认缩小为托盘图标，只隐藏主窗口；选择“退出程序”后，关闭会退出。
计时和可见提醒继续。退出时停止计时器、移除托盘图标，并释放 Pet、
气泡窗口和渲染资源。

## 资源、设置与位置

角色资源由 `assets/pets/cat-dog/manifest.json` 描述。构建时嵌入 manifest
和保留的 56 张 PNG（仅 Idle、Walk、Jump），运行时无需 assets 文件夹。
未使用的 Run、Fall、Hurt、Dead、Slide 不再保留或嵌入。启动时通过 GDI+ 内存流解码每个
角色的 `idle`、`walk`、`jump` 并保存在角色目录中；每个动画至少一帧，
按照 manifest 中的数字顺序取帧。替换图片或 manifest 后需要重新构建。

解码结果为预乘 alpha 的 BGRA。Pet 显示尺寸由原始图片尺寸和当前 DPI
计算，以 96 DPI 为基准；双线性插值用于缩放，跨 DPI 更新不会累积缩放。
命中测试读取当前缩放表面的 alpha，值小于 16 的像素不触发 Pet 交互。

设置入口位于主窗口、托盘和 Pet 菜单。角色、语言、主题和关闭行为立即
保存并应用；设置中的计时间隔以整数分钟输入，最少为 1，点击“返回”时
转换为秒保存。已有秒数向上取整显示分钟，未修改输入时保留原秒数；
例如配置为 30 秒时，设置中显示 1，主窗口显示 `00:30`。
修改后的分钟输入规范化到 1～71,582,788，空值或无法解析的输入按 1 处理。
主窗口倒计时始终显示存储的秒数。更改间隔会替换
剩余秒数，其他设置不会重置计时。未知角色回退到 `cat`。配置文件位于
`%APPDATA%\yinhaibo\stand-awhile\config.json`，以 UTF-8 保存；手工修改后需
重启程序。旧 `speech_bubble` 字段被忽略，并在保存配置时移除。

“重置为默认值”立即保存并应用其他默认配置：20 分钟、小猫、自动语言、
系统主题、关闭时缩到托盘、开始后自动隐藏。开机自启动保留当前值，
不更新启动项；面板保持打开。保存失败时保留面板原值并提示错误。

拖动允许 Pet 部分超出工作区，但至少保留一小块可见区域。拖动结束时
将显示器标识、工作区相对坐标和屏幕坐标保存到 UTF-8 文件
`%LOCALAPPDATA%\yinhaibo\stand-awhile\state.json`，与用户配置分开。
旧 `config.json` 中的 `pet_position` 不迁移，
在保存配置时移除；没有状态文件时使用默认位置。启动恢复位置时，先选择最
接近保存屏幕坐标的显示器；标识匹配时使用相对坐标，否则使用屏幕坐标，
最后将窗口限制在可用工作区内。丢失鼠标捕获会取消拖动，不触发点击确认。

## Windows 验证

在仓库根目录执行：

```powershell
cargo fmt -- --check
cargo test -- --test-threads=1
cargo build
```

发布构建使用 `cargo build --release`，但 `build.rs` 要求 Git 工作区干净。

手动检查：

0. 连续或同时打开程序，确认只有一个进程和一个托盘图标。主窗口隐藏或
   最小化后再次打开，应恢复已有窗口，运行中、暂停或结束的计时保持原状态，
   Pet 不应重新入场或消失。正常退出及在任务管理器结束进程后，应能重新启动。

1. 每次普通启动时确认只有主窗口可见、Pet 隐藏、计时未开始；三个按钮下方
   显示说明文字，在不同 DPI、中英文和明暗主题下均完整可读。
2. 点击主窗口开始按钮，确认开始完整倒计时；暂停、继续、重置的
   倒计时和按钮状态正确，开始后的首秒内也可以重置。重置后确认计时停止、
   剩余时间恢复配置时长，Pet 保持隐藏；退场动画期间立即重置也应如此。
   分别勾选和取消自动隐藏选项，从主窗口、托盘菜单、Pet 菜单或单击 Pet
   开始计时，确认只有勾选时隐藏主窗口。恢复主窗口后，暂停继续、重置再开始
   和点击提醒应遵循相同规则；切换选项本身不隐藏窗口，重启后保留选项。
3. 使用短间隔等待计时结束，确认 Pet 以 Jump 入场，随后 Walk；气泡
   显示期间 Idle，隐藏期间 Walk，文字包含提醒和点击说明；计时文本恢复配置时长，
   重置按钮禁用。允许上述计时延迟，不以精确的实际经过时间作为验收要求。
4. 在计时运行、暂停和归零状态切换语言、主题、角色或关闭行为，确认
   剩余秒数不变；在设置中修改间隔后点击返回，确认剩余秒数更新。
5. 切换 Cat 和 Dog，确认可直接生效，无需重启；切换语言时，主窗口、
   菜单、设置、说明、自动隐藏选项和气泡文字随之更新；保存设置不覆盖自动隐藏选项。
6. 在不同 DPI 的显示器之间拖动 Pet，确认尺寸和点击区域同步变化，
   往返拖动不会累积缩放；部分越界仍保持可拖动，透明区域不触发交互。
7. 拖动 Pet 后修改设置，再退出和重新启动，确认保存的位置未被设置
   覆盖；断开原显示器后启动并等待提醒，确认 Pet 落在可用工作区内。
8. 检查 Pet 和托盘菜单包含开始计时、显示主窗口、设置、关于和退出。
   隐藏或最小化主窗口，再从托盘/Pet 菜单打开设置或显示主窗口，确认恢复窗口，
   计时和 Pet 状态不变。
9. 默认选择“缩小为托盘图标”，分别在计时中和提醒显示时关闭主窗口，确认计时
   或提醒继续；通过托盘恢复主窗口。切换到“退出程序”后，关闭应退出程序。
   在缩小到托盘后重启 Windows 资源管理器，确认托盘图标重新出现，
   提示文字保持当前语言，双击和右键菜单仍可正常使用。
   计时进行中，托盘悬停提示应为“站一站（计时中）”或“Stand Awhile (Timing)”；
   暂停、重置、到期后恢复应用名称。运行中切换语言或重启资源管理器后，
   提示仍应反映当前语言和计时状态。
10. 多次打开和关闭设置及关于窗口，确认正常关闭、无残留窗口；关于
    窗口打开期间主窗口不可操作，关闭后恢复。
    在主窗口及设置输入框按 Enter/Escape，确认不会误触发设置或关于；
    确认 Tab/Shift+Tab 顺序、计时按钮空格/Enter 和页脚按钮空格操作正常。
11. 将生成的 EXE 单独复制到不含 assets 的目录并运行，确认 Cat、Dog
    及提醒动画都能加载。
12. 修改所有配置项，并在分钟输入框中输入一个尚未保存的值，然后点击
    “重置为默认值”。确认面板保持打开，分钟恢复 20、桌宠为小猫、语言自动、
    主题系统、关闭时缩小为托盘图标、开始后自动隐藏为“是”。分别在开机自启动
    为“是”和“否”时执行重置，确认该选项保留当前值、登录启动项不变。
    主窗口同步应用其他默认配置；返回和重启后均保持这些值。
    确认 Tab 顺序包含重置按钮，中英文、明暗主题及不同 DPI 下显示完整。
    重置按钮应与右下角“返回”在同一行、位于其左侧，间隔为 12 个逻辑单位，
    绘制样式与“返回”一致，无额外阴影或上浮效果；鼠标悬停显示手形光标，
    键盘聚焦仍显示焦点框，Tab 按顺序经过重置按钮和返回按钮。

## 后台自动计时启动模式

通过设置或配置文件启用 `launch_at_startup` 后，退出程序再执行：

```powershell
.\target\debug\stand-awhile.exe --autostart
```

本登录会话尚无实例运行时的行为：

| 参数 | `launch_at_startup` | 启动结果 |
| --- | --- | --- |
| 无 | `false` | 主窗口可见，等待手动开始，Pet 隐藏 |
| 无 | `true` | 主窗口可见，等待手动开始，Pet 隐藏 |
| `--autostart` | `false` | 主窗口可见，等待手动开始，Pet 隐藏 |
| `--autostart` | `true` | 主窗口从创建起隐藏，仅显示托盘，立即开始完整倒计时 |

补充手动验收：

1. 分别在“开始后自动隐藏主窗口”为“是”和“否”时后台启动，确认主窗口
   均不闪现、Pet 隐藏，托盘图标可恢复正在计时的主窗口。
2. 设置短间隔（可手工将配置中的 `period` 设为数秒），后台启动，等待
   自然到期，确认 Pet 正常入场、播放动画和显示气泡。
3. 在已有实例计时中、暂停和提醒中重复执行带参数命令，确认第二个进程
   静默退出，主窗口、Pet、剩余秒数和计时状态均不变。配置为 `false` 时亦如此。
4. 不带参数重复启动，确认恢复已有窗口，倒计时和 Pet 状态保持不变。

自动测试覆盖参数精确匹配、参数/配置四种组合、原生窗口创建时的可见性、
初始化期间不显示后台窗口，以及两种自动隐藏配置下的真实计时消息处理、
托盘恢复、到期 Pet 可见性和后台重复调用的状态保持。计时集成测试直接
发送 `WM_TIMER`，自然经过时间与实际 EXE 重复启动仍按上述步骤手动验收。
集成测试会短暂创建并删除测试托盘图标，不读写用户配置或状态文件。

## Windows 登录自启动

启动项位于当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，
值名 `Yinhaibo.StandAwhile`，类型 `REG_SZ`，内容为 `"当前 exe 完整路径" --autostart`。
默认关闭，不需要管理员权限。只操作此 Run 值，不访问 Windows 的
`StartupApproved` 禁用状态，也不修改其他程序的启动项。

Settings 中选择“是”或“否”时，先保存新配置，再注册或删除启动项。
删除不存在的值或键视为成功。注册表操作失败会恢复原配置和单选状态，
恢复配置失败时同时报告两次错误。分钟输入框中尚未保存的修改会保留。
该选项不向主窗口发送应用计时配置的消息，不改变当前计时、窗口或 Pet 状态。

主实例每次启动时按配置同步启动项。手工修改配置或移动 EXE 后，手动打开
程序即可同步；若旧实例仍在运行，应先退出它。启动时同步失败会提示错误，
主窗口、托盘和计时功能仍继续运行。

自动测试使用 `HKCU\Software\Yinhaibo.StandAwhile.Tests-<pid>-<序号>` 隔离键，
结束时删除测试键，不改真实 Run 项或用户配置。覆盖注册、路径更新、重复
注册/删除、缺少键或值、中文及空格路径、保留其他值、只读句柄引发的实际
注册表错误、配置保存和恢复失败，以及原生 Settings 单选状态恢复。

手动验收（尚未执行）：

1. 在运行、暂停和到期提醒状态下切换“开机自启动”，确认注册表值与选项
   一致，计时和窗口/Pet 状态不变；重复选择同一选项应成功。
2. 启用后退出，把 EXE 移到包含中文和空格的新目录，手动打开，确认启动项
   更新到新路径且包含双引号和参数。关闭后手工修改配置，再启动验证同步。
3. 启用后注销再登录，确认只有一个实例，主窗口不闪现、仅托盘可见，
   立即开始完整倒计时并正常提醒。取消后再次注销登录，确认不自动启动。
4. 在 Windows 启动应用设置中禁用本程序，再手动启动，确认禁用状态保持。
5. 在可恢复的测试环境限制该 Run 键写权限，验证设置切换失败时的提示、
   原配置和单选状态恢复；验证启动同步失败后程序仍可操作。结束后恢复权限。
