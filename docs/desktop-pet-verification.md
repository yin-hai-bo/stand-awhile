# 桌面 Pet 验证说明

## 当前行为

同一 Windows 登录会话只运行一个实例，使用 `Local\Yinhaibo.StandAwhile`
命名互斥量。重复启动最多等待 5 秒寻找已有主窗口，找到后恢复显示并尝试置前，
不修改计时或 Pet 状态；未找到则提示错误并退出，不创建第二个实例。
主实例正常退出或异常终止后，可再次启动。此阶段未实现后台启动或实际开机自启动。

每次启动时只显示主窗口，Pet 保持隐藏，计时器处于 `NotStarted`，不会自动开始计时。
主窗口三个按钮下方显示“倒计时结束后，小伙伴会提醒你起来活动活动。”，支持中英文和主题切换。
提醒时 Pet 播放原地 `walk`；气泡显示期间切换为 `idle`，气泡隐藏后回到
`walk`。动画不会自动改变桌宠位置，入场、退场和拖动会改变窗口位置。

点击 Pet 会滑出隐藏，并从配置的完整时长开始新一轮计时。开始按钮会
隐藏 Pet 并开始或继续计时；暂停会停止计时并隐藏 Pet；重置会恢复配置
时长、停止计时并保持 Pet 隐藏。

主窗口底部左侧显示“开始倒计时后自动隐藏主窗口”复选框，默认勾选，
选择立即保存到配置，重启后保留。勾选时，从主窗口、Pet 或菜单开始计时、
暂停后继续、重置后开始以及点击到期提醒，都会隐藏主窗口。取消勾选时，
所有入口均不自动隐藏。切换勾选状态不立即隐藏窗口，只影响之后的开始操作。
此行为与关闭窗口时是否缩到托盘的设置无关，隐藏后可从托盘重新打开主窗口。
设置面板同时提供“开始后自动隐藏主窗口”的“是／否”单选项，立即保存，
与主窗口复选框使用同一配置并同步选择。
设置面板提供“开机自启动：是／否”，默认“否”，选择立即保存到
`launch_at_startup` 配置字段。目前只存储和加载选择，不实现实际开机自启动。
进入设置时焦点位于倒计时分钟数输入框；Tab 导航包含右下角“返回”按钮，
并循环回到输入框，Shift+Tab 可反向导航。
主窗口的 Tab 顺序为开始、暂停、重置、自动隐藏复选框、关于、设置，再循环；
禁用的按钮自动跳过，Shift+Tab 反向导航。计时按钮显示焦点框，空格或 Enter 触发。

计时归零后，主窗口停止计时器，Pet 从所在显示器较近的顶部或底部边缘
以 `jump` 入场，目标位置限制在工作区内。入场和 Jump 都完成后切换到
`walk`，再延迟 500 ms 显示气泡。气泡显示 5 秒、隐藏 10 秒，循环播放
固定提醒和点击说明；文字跟随应用语言，支持中文和英文。主窗口计时文本
停留在配置的完整倒计时时长。

关闭主窗口默认缩小为托盘图标，只隐藏主窗口；选择“退出程序”后，关闭会退出。
计时和可见提醒继续。退出时停止计时器、移除托盘图标，并释放 Pet、
气泡窗口和渲染资源。

## 资源、设置与位置

角色资源由 `assets/pets/cat-dog/manifest.json` 描述。构建时嵌入 manifest
和所有 PNG，运行时无需 assets 文件夹。启动时通过 GDI+ 内存流解码每个
角色的 `idle`、`walk`、`jump` 并保存在角色目录中；每个动画至少一帧，
按照 manifest 中的数字顺序取帧。替换图片或 manifest 后需要重新构建。

解码结果为预乘 alpha 的 BGRA。Pet 显示尺寸由原始图片尺寸和当前 DPI
计算，以 96 DPI 为基准；双线性插值用于缩放，跨 DPI 更新不会累积缩放。
命中测试读取当前缩放表面的 alpha，值小于 16 的像素不触发 Pet 交互。

设置入口位于主窗口、托盘和 Pet 菜单。角色、语言、主题和关闭行为立即
保存并应用；设置中的计时间隔以整数分钟输入，最少为 1，点击“返回”时
转换为秒保存。已有秒数向上取整显示分钟，未修改输入时保留原秒数；
主窗口倒计时始终精确显示秒数。更改间隔会替换
剩余秒数，其他设置不会重置计时。未知角色回退到 `cat`。配置文件位于
`%APPDATA%\yinhaibo\stand-awhile\config.json`，以 UTF-8 保存；手工修改后需
重启程序。旧 `speech_bubble` 字段被忽略，并在保存配置时移除。

拖动允许 Pet 部分超出工作区，但至少保留一小块可见区域。拖动结束时
将显示器标识、工作区相对坐标和屏幕坐标保存到 UTF-8 文件
`%LOCALAPPDATA%\yinhaibo\stand-awhile\state.json`，与用户配置分开。
旧 `config.json` 中的 `pet_position` 不迁移，
在保存配置时移除；没有状态文件时使用默认位置。启动恢复位置时，先选择最
接近保存屏幕坐标的显示器；标识匹配时使用相对坐标，否则使用屏幕坐标，
最后将窗口限制在可用工作区内。丢失鼠标捕获会取消拖动，不触发点击确认。

## Windows 验证

在仓库根目录执行：

```powershell
cargo fmt -- --check
cargo test
cargo build
```

发布构建使用 `cargo build --release`，但 `build.rs` 要求 Git 工作区干净。

手动检查：

0. 连续或同时打开程序，确认只有一个进程和一个托盘图标。主窗口隐藏或
   最小化后再次打开，应恢复已有窗口，运行中、暂停或结束的计时保持原状态，
   Pet 不应重新入场或消失。正常退出及在任务管理器结束进程后，应能重新启动。

1. 每次启动时确认只有主窗口可见、Pet 隐藏、计时未开始；三个按钮下方
   显示说明文字，在不同 DPI、中英文和明暗主题下均完整可读。
2. 点击主窗口开始按钮，确认开始完整倒计时；暂停、继续、重置的
   倒计时和按钮状态正确，开始后的首秒内也可以重置。重置后确认计时停止、
   剩余时间恢复配置时长，Pet 保持隐藏；退场动画期间立即重置也应如此。
   分别勾选和取消自动隐藏选项，从主窗口、托盘菜单、Pet 菜单或单击 Pet
   开始计时，确认只有勾选时隐藏主窗口。恢复主窗口后，暂停继续、重置再开始
   和点击提醒应遵循相同规则；切换选项本身不隐藏窗口，重启后保留选项。
3. 使用短间隔等待计时结束，确认 Pet 以 Jump 入场，随后 Walk；气泡
   显示期间 Idle，隐藏期间 Walk，文字包含提醒和点击说明。
4. 在计时运行、暂停和归零状态切换语言、主题、角色或关闭行为，确认
   剩余秒数不变；在设置中修改间隔后点击返回，确认剩余秒数更新。
5. 切换 Cat 和 Dog，确认可直接生效，无需重启；切换语言时，主窗口、
   菜单、设置、说明、自动隐藏选项和气泡文字随之更新；保存设置不覆盖自动隐藏选项。
6. 在不同 DPI 的显示器之间拖动 Pet，确认尺寸和点击区域同步变化，
   往返拖动不会累积缩放；部分越界仍保持可拖动，透明区域不触发交互。
7. 拖动 Pet 后修改设置，再退出和重新启动，确认保存的位置未被设置
   覆盖；断开原显示器后启动并等待提醒，确认 Pet 落在可用工作区内。
8. 检查 Pet 和托盘菜单包含开始计时、显示主窗口、设置、关于和退出。
9. 启用缩小为托盘图标，分别在计时中和提醒显示时关闭主窗口，确认计时
   或提醒继续；通过托盘恢复主窗口。默认关闭行为则应退出程序。
   在缩小到托盘后重启 Windows 资源管理器，确认托盘图标重新出现，
   提示文字保持当前语言，双击和右键菜单仍可正常使用。
10. 多次打开和关闭设置及关于窗口，确认正常关闭、无残留窗口；关于
    窗口打开期间主窗口不可操作，关闭后恢复。
11. 将生成的 EXE 单独复制到不含 assets 的目录并运行，确认 Cat、Dog
    及提醒动画都能加载。
